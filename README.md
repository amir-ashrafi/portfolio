# Portfolio Website

A modern, responsive personal portfolio to showcase skills, projects, and contact information.

- **Framework:** Next.js (v15)
- **UI:** React (v19) + Tailwind CSS (v3)
- **Animations:** `motion` (Framer Motion API)
- **Icons:** `react-icons`
- **Deploy:** Vercel
